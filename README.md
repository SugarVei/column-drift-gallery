# Column Drift

一个支持五列漂移、双螺旋、速度折叠、互动照片球、斜向照片墙和无边照片墙的全屏相册。

## 使用

这是普通的静态网站，无构建步骤、无外部字体、无第三方 JavaScript 依赖。将整个目录交给静态网站托管服务即可发布。也可以在目录中运行 `python -m http.server 8768`，然后访问 `http://localhost:8768`。

- 用底部「展示风格」切换。五列漂移支持设置 2–6 列，展示风格和列数保存在本机。
- 双螺旋在左右两列各显示一组，每组都沿自己的竖轴旋转并上升。电脑可纵向拖动，手机可横向滑动，也支持滚轮和方向键。被操作的一组在闲置 1 秒后恢复自动旋转。
- 底部的「白底」或「黑底」按钮切换背景。背景选择保存在当前浏览器。
- 速度折叠是横向照片带。拖得越快，拱起和折转越明显，松手后会回平并吸附到中间照片。支持箭头、点选卡片、滚轮和键盘，空闲时自动切换。
- 互动照片球占满页面可用短边。点击时把照片放大到接近球体直径，球体继续在虚化背景中旋转。方向键旋转，Enter 打开最前面的照片。
- 斜向照片墙展示六列较小的竖图。点击任意一列暂停，再点一次从原位置继续。
- 无边照片墙支持鼠标左键或手指四向拖动。单击照片查看大图，关闭后保持原位置。用浏览器返回键或 Escape 回到相册设置。
- 每列每 1.5 秒移动一张卡片的步距，等于第一版中间列的节奏；奇数列向上、偶数列向下，速度大小相同。
- 每列 8 张照片，12 秒完成一个完整周期。默认的 40 张照片正好放满 5 列。切换列数或新增照片后，超出一组的照片可用“换一组”查看。
- 动态风格打开即展示，无边照片墙只在拖动时移动。保留全屏和隐藏控制栏功能。
- 点击“添加照片”可选择多张图片。新照片排在前面，立即进入画面。支持常见的 JPG、PNG、WebP、GIF、AVIF、BMP；动图作为静态照片显示。
- 新照片只保存在当前浏览器的 IndexedDB，刷新后仍可查看。它们不会上传到服务器，不会改变其他访客看到的默认相册，也不会自动跨设备同步。
- 在「我的照片」可勾选「仅展示我添加的照片」，用自己的相册替换默认展示内容。这里也可移除单张照片，或清除新增照片恢复默认相册。
- 如果浏览器存储不可用或空间不足，页面会明确提示新增照片只能保留在当前页面。

## 实现

所有风格共享 `photos.js` 的 40 张默认照片和浏览器里新增的照片。参考演示观察与实现要求见 [展示风格提示词](coverflow-prompts.md)。

动画由 `requestAnimationFrame` 按真实时间计算一个共享像素距离，奇数列取负方向、偶数列取正方向；每列的绝对速度严格共用 `cycle / 12`，不设置独立速度或缓动。逐帧只更新照片带的 `translate3d`，没有时间轴、文字或进度控件刷新。照片预解码后开始展示，合成层仅用于各列照片带，以 60 帧及更高刷新率的流畅播放为目标；实际帧率取决于设备、浏览器和屏幕刷新率。每列以完整周期复制照片，首尾无缝。没有 CSS 关键帧、卡片缩放、旋转或淡入淡出效果。

上线前可检查：初次打开自动播放、五列交替反向且速度大小相同、0 秒和 12 秒一致、手机竖屏、添加照片后刷新保留、单张删除、恢复默认、全屏与隐藏控制栏。

默认照片的公开发布由相册所有者授权；访客应只添加自己有权使用的照片。

## 离线单文件

运行 `python tools/build_standalone.py "Column Drift 照片动画.html"` 可把样式、脚本和全部默认照片打包进一个 HTML 文件，双击即可离线播放。打包工具只用 Python 标准库，网站本身不需要 Python。

运行 `python tools/build_standalone.py "无边照片墙.html" --mode wall` 可生成一份打开即显示无边照片墙的单文件。按 Escape 回到相册后，可用「添加照片」导入图片，再在「我的照片」选择仅展示自己添加的照片。
